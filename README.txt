How to start:
1.net start MongoDB (ps. For MongoDB Compass, open it and create a new connect)
2.open cmd
3.cd path*/server(*:the real path in your computer)
4.npm install
5.node scripts/fix-location-text-index.js
6.npm run dev
7.open another cmd
8.cd path*/client
9.npm install
10.npm install react-csv leaflet react-leaflet date-fns
11.npm run dev
12.Ctrl+Click http://localhost:5173
13. Please first register for an account then try login to experience login animation.
